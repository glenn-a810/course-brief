## 3) 타일 라벨-값 중복 정리

라벨과 값이 같은 말을 두 번 보이던 곳(예: `연습장 → 연습장`, `프로샵 → 프로샵`)은
**값에서 라벨을 걷어내고 상태 표기만 남기는** 방식으로 정리했다.

| 이전 | 이후 |
| --- | --- |
| 프로샵 → 프로샵 / 프로샵 운영 | 프로샵 → 운영 |
| 연습장 → 연습장 / 연습장 12타석 운영 | 연습장 → 운영 / 12타석 운영 |
| 사우나 → 사우나 있음 / 사우나 운영 | 사우나 → 운영 |
| 복장 규정 → 복장 규정 안내 | 복장 규정 → 안내 |
| 2인 플레이 → 2인 플레이 불가 | 2인 플레이 → 불가 |
| 락카 → 락커 운영 / 락카(후불 결제) | 락카 → 운영 / 운영(후불 결제) |
| 5인 플레이 → 5인 플레이 가능(리무진 카트) | 5인 플레이 → 가능(리무진 카트) |
| 숏게임 연습장 / 전 홀 매트 티샷 | 숏게임 전용 / 전 홀 |

- 값이 라벨을 그대로 되풀이하는 59건이 전부 사라졌고, 값 앞머리에 라벨이 붙어 있던 754건도 정리했다.
- 렌더러에도 같은 규칙을 한 줄 방어로 넣었다(`web/assets/app.ts` `tile()` — 값이 라벨과 같으면 `운영`).
  새 수집분이 같은 형태로 들어와도 화면 중복이 생기지 않는다.
