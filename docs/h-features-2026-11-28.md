# H 기능 1차 — 총비용 계산기 · 조건 필터·지도 · 후보 비교 · 예약 채널 (2026-11-28)

v2.9.16 위에 `coursebrief_v2916_feature_proposal.md` 의 우선순위 높음 중 **데이터 추가 없이 바로 만들 수 있는 4개(H1·H4·H5·H6)** 를 얹었다.
새 화면도 데이터 규칙을 그대로 상속한다 — `null`=미확인, 없는 값은 계산에서 빼고 뺐다고 적는다, 카트·캐디는 팀 기준 1회.

## 1. H1. 라운드 총비용 계산기

- 위치: 상세 `01 요금 · 예약` 의 요금 카드 바로 아래(`#cost-calc`), 그리고 hero 의 `예약하기` 옆.
- 입력: 인원 `2 / 3 / 4 / 5` · 요일 `주중 / 주말` · 홀수 `18홀 / 9홀` · 옵션 `카트 / 캐디피`.
- 출력: 그린피(인원 × 1인가) + 카트(팀 1회) + 캐디피(팀 1회) → **팀 합계 / 1인당**, 근거 칩(공식 요금표·관측 최저가)과 확인일.
- 인원 토글은 `ops.two_player / three_player / five_player` 원문을 보수적으로만 읽는다.
  - `불가`로 시작하는 문장 → 버튼 비활성 + 이유 표시(예: `불가(4인 필수타임)`).
  - `가능(추가요금)` 처럼 조건이 붙은 문장 → `조건부` + 원문 병기.
  - 값이 없으면 `미확인` — 4인 요금이 적용되는 구장이 많다는 안내를 함께 띄운다.
- 9홀은 `official_detail.green_detail` 의 `9홀 …` 절에서 주중·주말 1인가를, `cart_detail` 에서 9홀 카트료를 읽어낼 때만 열린다.
  인식하지 못하면 9홀 버튼을 잠그고 `미확인`으로 표시한다(18홀 요금을 나눠 추정하지 않는다).
- 카트·캐디가 없으면 합계에서 빼고 `미확인 항목 제외 합계` 라고 적는다. 5인은 카트 요금이 다른 구장이 있어 별도 확인 문구를 붙인다.
- `정산 문구 복사` / `공유하기`(Web Share API → 클립보드 폴백).

## 2. H4. 조건 필터 8종 · 정렬 보강 · 지도 뷰

- 필터: 카드 배지로만 있던 8종(`노캐디·2인 가능·야간·사우나·숙박·셔틀·연습장·식당`)을 `#tag-chips` 로 승격. 다중 선택은 AND.
  칩의 숫자는 지금 걸린 다른 필터(상태·지역·형태·홀수·요금)까지 반영해 다시 계산한다.
- 정렬: `4인 총액 낮은순/높은순`(그린피×4 + 카트 + 캐디), `평점 높은순` 추가.
- URL: `#/?tags=y,f&sort=total-asc&view=map` — 조건·정렬·보기 상태가 모두 해시에 남아 링크로 공유된다.
- 지도: 목록/지도 토글(`view=map`). Leaflet + OpenStreetMap 타일(무료·키 없음)을 **지도를 처음 열 때만** 내려받는다.
  - 국가 배율(≤7)에서는 칸별 묶음(밀집 지역은 숫자, 한 곳뿐인 칸은 점) → 누르면 확대, 8단계부터 개별 그린피 핀.
  - 핀 → 구장 미리보기 카드(지역·그린피·상세 링크). 다크 모드는 타일을 반전·채도 조정해 TDS 다크 톤에 맞춘다.
  - 타일을 못 받으면 지도만 감추고 목록으로 돌아가는 안내를 띄운다.

## 3. H5. 후보 비교(최대 4곳) + 공유 링크

- 담기: 목록 카드의 `비교` 버튼, 상세 hero 의 `비교 담기`. `localStorage.coursebrief-compare` 에만 저장(로그인 없음).
- 하단 고정 바: `N곳 담김 · 비우기 · 비교표 보기` (모바일은 탭바 위).
- 비교 화면 `#/compare?ids=kr-golf-0002,kr-golf-0001,kr-golf-0005`:
  - 핵심 10행(주말/주중 그린피 · 4인 총액 · 카트 · 캐디피 · 2인 · 노캐디 · 야간 · 숙박 · 취소·위약 · 예약 오픈) + `추가 정보`(3·5인 · 홀·형태 · 평가 · 입지 · 렌탈 · 전화).
  - 값이 없는 칸은 `미확인`. 첫 열 고정 + 가로 스크롤, `<caption>` 제공.
  - `비교 링크 복사` / `공유하기` — 지금 화면의 해시를 그대로 보내므로 받는 사람은 앱 없이 같은 표를 연다.

## 4. H6. 예약 채널 딥링크

- 상세 hero 의 `예약하기`(primary) → 채널 바텀시트, `01 요금 · 예약` 아래 `예약 채널` 블록.
- 채널: 공식 홈페이지 · 카카오골프예약 · 골프존 티스캐너 · 스마트스코어 · 티픽(데이터에 구장 페이지가 있을 때) · 네이버 검색 · 전화.
- 구장별 페이지 주소를 공개하지 않는 플랫폼은 각 채널 공식 주소로 보내고 `채널에서 구장명 검색` 이라고 행마다 밝힌다. 시트에서 `구장명 복사` 제공.
- `가격·재고는 채널에서 확인`, `코스브리프는 예약을 대행하지 않습니다` 문구 고정.
