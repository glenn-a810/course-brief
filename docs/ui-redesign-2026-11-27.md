# UI/UX 전면 리디자인 (2026-11-27)

## 배경

목록·상세가 텍스트 나열에 가까워 "540곳을 비교해 예약 전 확신을 얻는" 과업을 돕지 못했다.
제3자 UI/UX·접근성 리포트(F-01~F-31)의 P0·P1 결함과 "인포그래피·정보 위계" 요구를 함께 반영해
목록·상세·렌탈·데이터 화면을 다시 설계했다.

## 화면 구조

### 목록 `#/`
- 히어로를 1줄 제목 + 검색으로 축소(모바일 126px). 필터는 접기/펼치기(데스크톱은 첫 페인트부터 펼침).
- 결과 요약: `480곳 표시 · 구장 512 · 전체 540곳` + `숨김 28곳 보기`(상태 필터로 숨은 수).
- 카드: 이름(h3)·지역·상태 배지 → 홀/이용형태/평점 → 특징 태그(노캐디·2인·야간·사우나·숙박…) → **그린피 강조(하단 좌측)**.
  가격이 없어도 "확인 안 됨"을 같은 자리에 두어 카드 높이가 흔들리지 않는다.
- 검색+필터가 겹치면 "검색 결과 68곳 중 67곳이 다른 조건으로 제외" 안내 + 조건 칩(개별 해제).

### 상세 `#/c/{id}`
1. **요약 히어로**: 상태/홀/이용형태 배지, h1, 위치·최단 IC·업데이트, KPI 타일(홀·파·전장·형태·평점),
   44px 액션(전화·홈페이지·지도), **그린피 카드**(주중·주말 최저 + 근거 라벨 + 카트·캐디).
2. `01 요금·예약` — 주중/주말/카트/캐디 카드, 관측 최저·회원제 요금, 공식 요금표(접기),
   **취소·위약 타임라인**(주중 D-3 / 주말 D-4 밴드), 예약 오픈 주기.
3. `02 코스 스펙` — **SVG 전장 게이지**, 홀 구성·파·코스명, **잔디 3색 도트 카드**, KGA 레이팅(접기).
4. `03 현장 운영` — 아이콘 타일 + 가능/불가/조건부 배지, 확인하지 못한 항목 접기.
5. `04 부대시설` — 아이콘 타일(휴장일은 '없음=연중 운영'으로 뒤집어 판정).
6. `05 공지·브리핑` — 운영 알림, 라운더 평가 막대, **최근 공지**(클럽·장비 상품 소식은 분리해 접기).
7. `06 동일 부지 코스`, `07 클럽 렌탈`(자체 대여 + 권역 배송 업체).
8. `08 데이터 기준`(관리자 모드에서는 영역별 충실도).

### 클럽 렌탈 `#/rental`
- 예약 가능/중단 배지, 중단 업체 하단 정렬, 권역 필터, 1일 기준가 파싱(불가하면 원문), 44px 전화·홈페이지 CTA.

### 데이터 `#/about`
- 통계 타일, **영역별 충실도 프로그레스 바**, 7개 영역 카드, 수집 원칙.

## 디자인 시스템
- 중성 배경(#f5f5f7 / #000) + 표면(#fff / #1c1c1e) + 선 + 글자 4단. 강조색은 가격·선택·포커스에만.
- 라이트/다크/자동 3택(테마 메뉴), 첫 페인트 전 적용.
- 숫자 tabular-nums, 카드 16px·타일 12px 라운드, 아이콘은 인라인 SVG 24px 스트로크.
